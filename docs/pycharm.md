# Installation using PyCharm

Starting from a blank project, I would advise to use the package manager and install `si_ref_point` as an external 
package (via the "python package", second icon from the top on the right vertical toolbar.) One can "add package" either 
from disk or from git. The latest version works also if you download as a zip file from GitHub (`setuptools_scm` removed 
to allow that).

One can tick the "editable" box while doing so, to achieve the same effect as the "pip -e" option.

Then, upon successful installation, opening a terminal via the 3rd icon from the bottom would give you access to a 
functional "`generate_turtle_files`" command and generate the TTLs.

Reading and editing the `si_ref_point` code is done through using the "Open..." option from the main menu, and attach 
it to the current project.
